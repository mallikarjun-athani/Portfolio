# Mallikarjun Athani Portfolio Website

A polished personal portfolio website built with HTML, CSS, and JavaScript to showcase projects, skills, education, achievements, GitHub stats, and contact details.

## Overview

This website is designed to present a professional portfolio with an interactive hero section, animated project cards, responsive layout, custom cursor effects, and a contact form that submits directly via FormSubmit.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern glassmorphism styling and animated background effects
- Project sections with live project links
- GitHub stats integration using the GitHub API
- Downloadable resume button
- Contact form with message field and email submission
- Smooth scrolling navigation and hover animations

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts (Inter, Fira Code)

## Project Structure

- `index.html` — Main portfolio landing page
- `style.css` — Custom styling and responsive layout
- `script.js` — Interactive behaviors and GitHub API integration
- `6th sem updated resume.pdf` — Resume file available for download
- `profile.jpeg` — Profile image used in the hero section

## Local Setup

To run the project locally, open `index.html` in your browser or use a local web server.

### Using Python server

```powershell
cd C:\xampp1\htdocs\Portfolio
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Deployment

This static portfolio is ideal for deployment on Vercel, Netlify, GitHub Pages, or any static hosting provider.

### Deploy on Vercel

1. Push the repository to GitHub.
2. Create a Vercel account at https://vercel.com.
3. Import the GitHub repository and deploy the project.

## Notes

- The contact form posts submissions to `formsubmit.co`.
- The GitHub stats section updates automatically using live data from the GitHub API.
- If you rename the resume file, update the download link in `index.html`.
